# plen1lune.github.io

Personal homepage of Licheng Luo, built with Jekyll and served by GitHub Pages.

- Page content lives in `index.md`, `publications.md`, `honors.md`, `hobbies.md`.
- News items and publications are data files: `_data/news.yml`, `_data/publications.yml`.
- Layout: `_layouts/default.html`; styles: `assets/css/main.css`.
- Resume PDF and its LaTeX source: `file/RL_Resume/`.

Local preview: `jekyll serve` (or `bundle exec jekyll serve` with the `github-pages` gem).
